# VLM 扫描页 OCR 接入报告（M2 / 需求 F1.9）

> 日期：2026-09-16 ｜ 状态：已闭环（真实 Qwen-VL 跑通）

## 背景

红页（扫描件 / 纯图页 / 乱码页）PyMuPDF 几乎抽不出可信文本。M1 阶段 `_transcribe_red_pages` 是空桩（返回 `[]`），红页只能原文降级入库。本次把 M2 的 VLM 转录真实接上：红页渲染成图片 → Qwen-VL 做 OCR → 转录文本作为带正确页码的块入库，可被检索命中。

## 关键修复（M1 桩的坑）

`DashScopeTranscriber.transcribe` 原实现传 `file://{page_image_path}` 给 DashScope OpenAI 兼容接口——**远程 API 拒收本地路径**，必须传 **base64 data URL**。这是 M1 桩无法直接启用的最隐蔽原因。改法：调用方（pipeline）渲染页面得到 PNG 字节，transcriber 内部 `base64.b64encode` 后拼 `data:image/png;base64,...`。

## 改动清单

| 文件 | 改动 |
|---|---|
| `app/ingestion/vlm.py` | `DashScopeTranscriber.transcribe(page_image_bytes, page_no)`：改为接收 PNG 字节 + base64 data URL；OCR 提示词要求「保留标题/段落/表格结构、Markdown 输出」；调用后 emit `log_llm_usage(node="vlm_ocr")`（token 是一等公民）。ABC 签名同步改 `page_image_bytes`。`get_transcriber()` 走 `settings.vlm_enabled` + `settings.has_api_key`。 |

| `app/ingestion/pipeline.py` | 实现 `_transcribe_red_pages`：逐红页 PyMuPDF 渲染（zoom=1280/max(w,h) → 长边≤1280px，控体积且落 Qwen-VL 像素上限）→ `transcriber.transcribe(png, page_no)` → 成功则生成 `Block(paragraph, page=page_no, metadata={source:"vlm_ocr"})`；红页原文块在 `run_document` 中移除以 OCR 块替换。vlm_note 文案改为「N 个红页已 VLM 转录为 OCR 文本块」。 |

## 设计要点

- **页码溯源**：OCR 块带 `page=原红页页码` → chunk 的 `page_num` 正确（不再指错页）。OCR 块是 `paragraph`，按普通段落切分+向量化，可被检索命中（而非 `figure_transcript` 原子块导致不可切）。
- **降级不崩（R7）**：无 Key / `VLM_ENABLED=0` / 单页渲染或转录失败 → 返回 `None` → 编排层保留红页原文降级入库 + `vlm_note` 明示。单页失败不影响整批。
- **`max_pages` 上限**：`DashScopeTranscriber.max_pages`（默认 20）防极端多红页文档烧钱。
- **token 记账**：每次 VLM 调用 emit `event=llm_usage, node=vlm_ocr`，prompt_tokens 含图片 token 成本（`est_cost_cny=0.0`，摄取期成本未计入按查询账本，token 数已记录）。

## 验证结果

- **合成扫描页探针**：造「文字烤进图片、无文本层」的 PDF → `grade_page` 判 `red`(0 文本字符) → Qwen-VL 还原全文（含标题「员工请假管理制度（扫描件）」「年假 5 天」「每季度保养一次」）。
- **回归 `scripts/verify_vlm_ocr.py`**：**PASS 10/10**（EXIT=0）。
  - 离线（FakeTranscriber）：fixture 判 red / 产出 1 OCR 块 / page 溯源正确 / `source=vlm_ocr` / paragraph / 红页原文块移除 + OCR 块追加。
  - 真实（gate: VLM_ENABLED+Key）：合成扫描页跑真实 Qwen-VL，恢复关键文字「保养/每季度」。
- **全量 `ingest --rebuild`**（VLM_ENABLED=1）：38 文档全 ok；`sample_scan_page.pdf` 报告 `◐ [VLM] 1 个红页已 VLM 转录为 OCR 文本块`；降级列全 `real`；锚点词表重建 4060 词。
- **`verify_pdf_structure.py`**：仍 PASS（解析层未改，VLM 在 ingest 阶段生效，不破坏既有结构）。

## 成本 / 风险

- 每次红页 1 次 Qwen-VL 调用（约 2-3s/页，图片 token 几十~几百）。语料当前仅 1 红页，成本可忽略；真实多扫描页文档靠 `max_pages` 兜底。
- Qwen-VL 对纯空白扫描页会返回「（空白页面）」——属正常 OCR 结果，非故障。
- 仍非覆盖项：**图文混排 PDF 的版面对齐**（图片+文字混排的精细切分）未做。
